# ⚔️ The 33 Strategies of War — Interactive Guide

An interactive web experience inspired by Robert Greene's **The 33 Strategies of War**, presenting strategic principles through a clean, immersive digital interface.

Explore the strategies, their core ideas, and historical applications in an easy-to-navigate format.

## ✨ Features

- ⚔️ Explore the **33 Strategies of War**
- 📖 Concise explanation of each strategy
- 🏛️ Historical applications & examples
- 🃏 Interactive strategy cards
- 👤 Dedicated author section
- 🌙 Dark / Light theme
- ✨ Minimal, responsive interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
